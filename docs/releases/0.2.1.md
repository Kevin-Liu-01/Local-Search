# local-search 0.2.1

Native crate: `local-search` 0.2.1. npm bridge: `@kevinliu01/localsearch` 0.2.1,
pinned to the same native version.

## Changes

- Wait for the new document and settled search results before returning content.
- Keep navigation and readiness within one operation deadline.
- Verify live browser connections for cache hits without unnecessary tab attachment.
- Streamline browser transport and search execution while preserving stable output.
- Preserve bounded recording events and isolate retained-session requests.

The implementation is commit `0ca8178`. Public command names, browser selection,
compatibility aliases, and machine output contracts remain unchanged.

## Upgrade

```sh
cargo install local-search --version 0.2.1 --locked --force
# Or, with Node.js 18+ and Rust/Cargo:
npm install -g @kevinliu01/localsearch@0.2.1
```
